How to read transaction medians, access, schools and estate context

Project grouping and sample size

A project row combines observed unit sizes, layouts, floors and sale types. Median price and area are descriptive, not like-for-like unit comparisons. Always inspect total and recent sample counts before relying on a median.

Recent versus all

The recent window is the latest 12 months in the committed dataset. “Recent vs all” compares that median with the full observed project median, which includes the recent period. It is mix-sensitive and is not an appreciation rate.

Price comparisons

“Vs district” compares the project’s full-window median price per square metre with the postal-district median across mixed projects and units. It is a screening signal, not a controlled valuation or forecast.

MRT and location quality

The nearest-station field uses operational MRT/LRT records and straight-line distance. Most rows use a matched project geocode; fallbacks use the surrounding estate centroid and must not be interpreted as project distance.

School diagnostics

Primary, secondary and junior-college fields are project-coordinate radius diagnostics with sourced selectivity proxies where available. Verify MOE eligibility boundaries and current admissions rules independently.

Framework boundary

Provision and private Value are joined from the surrounding estate context. Private Value remains separate from HDB, and its sample depth stays visible. Neither field is a project score or recommendation.

Decision boundary: use this page to discover projects and inspect achieved evidence. Before a purchase, compare the same unit size and layout, verify walking routes and school eligibility, inspect maintenance and lease details, and model financing and exit costs separately.
