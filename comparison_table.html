How to read bands, gaps, price adjustments and missing evidence

Bands and gaps

A, B+, B, C, D and F are framework bands, not a universal winner scale. Gap labels use the canonical ±0.5 dead band: values inside it are shown as matched, not directional.

Value evidence

The price adjustment is the segment model’s capped residual multiplier. Above 1 means price evidence sat below its model baseline; below 1 means above baseline. It is not a forecast or an instruction to buy.

Evidence quality

Direct and proxy bases remain visible. Samples below 100 are reported as bands only. “No data,” “not covered” and the non-residential X gate are intentionally distinct.

Context fields

D is a current disruption-loss multiplier applied in Liveability. Noise is an expressway-distance proxy, Lease is HDB-specific, and employment access is not an automatic price-growth forecast.

Decision boundary: default to an estate profile. Only rank when archetype, persona, horizon and private household anchors genuinely match and the difference exceeds the framework noise floor.
