Invariant — No cross-archetype ranking
Raw provision scores are not ranked across different archetype tags (A–G). Only compare: same archetype + same horizon + same persona + score diff > ±0.3.
Primary signal — Provision–Liveability Gap
Gap = liveability_band_numeric − provision_band_numeric
Positive: lovable beyond checklist (e.g. TENGAH T15 gap_ls = +3.0)
Negative: over-equipped for this persona
Invariant — HDB ≠ Private
HDB and private are separate universes — modelled independently, never blended or ranked against each other. Divergence (e.g. QST HDB=D vs private=B) is a signal, not an error.
Output — Profile not ranking
Default output is a profile per estate. The framework's central thesis: in a uniformly-provisioned city, price-for-equivalent-provision is the discriminating axis.
