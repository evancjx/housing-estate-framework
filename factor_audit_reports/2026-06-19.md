## 1. Critical gaps (propose adding)

Factors where ≥2 sweeps converged, that pass the three axioms, and that have a Singapore open-data feed.

### 1a. Aircraft noise exposure
- **Description.** Distance to / overflight density of Changi, Seletar, Paya Lebar flight paths.
- **Provenance.** PARTLY_MEASURED. Flight-track data is partially public via CAAS; full noise-contour modelling is gated. NEA noise zones cover some of this.
- **Proposed weight bucket.** 0.02–0.04 (similar to existing `noise` expressway component, which it complements rather than duplicates).
- **SG datasets.** CAAS public flight tracks; NEA noise zones; NEA monitoring stations. Possibly augmented with OSM aerodrome polygons + simple buffer model. See catalog B20.
- **Discriminating power.** HIGH at the tails: East Coast / Marine Parade / Tampines / Pasir Ris under Changi approach diverge sharply from West/North estates. Will move scores well beyond ±0.3 on affected estates.
- **Cross-references.** Sweep A (WHO Healthy Cities air/noise indicators); Sweep C tier-2 (buyers explicitly cite "Changi flight path damn loud"). Borders existing `noise` (which is expressway-only).

### 1b. Ambient air quality (PM2.5, NO₂)
- **Description.** Annual-mean PM2.5 exposure + haze-day frequency at the nearest NEA station, with a road-class-buffer correction for sub-regional variation.
- **Provenance.** PARTLY_MEASURED. NEA's 5 regional PSI bins are spatially coarse (the honest tag); the road-class augmentation is a model, not a measurement.
- **Proposed weight bucket.** 0.03–0.04. Could be carved from current `env` (0.05) which is PARTLY_MEASURED and would tighten when air-quality is split out.
- **SG datasets.** NEA real-time REST APIs `/v1/environment/psi`, `/v1/environment/pm25`, `/v1/environment/air-temperature` (free, no key). See catalog B1.
- **Discriminating power.** MODERATE. North/East-West real differences (Tuas industrial proximity); central/eastern estates partially saturate. Should clear ±0.3 on Jurong/Tuas-adjacent estates.
- **Cross-references.** Sweep A (WHO, EPA EJScreen, OECD How's Life regional); Sweep B (NEA REST APIs). Borders `env` (currently PARTLY_MEASURED), `noise`.

### 1c. Pedestrian-network / first-and-last-mile shelter quality
- **Description.** % of walk-to-MRT path that is sheltered/covered, plus pavement continuity in 400m / 800m buffer. The framework's `conn` definition (§1.1 row 1) names "first/last-mile shelter" as a sub-metric but currently doesn't measure it.
- **Provenance.** PARTLY_MEASURED. OneMap walking-routes theme tags some shelter status; full coverage is uneven.
- **Proposed weight bucket.** No new weight; refine `conn` (0.15) by adding the sub-metric. Reweight `conn` sub-metrics, not the top-level component.
- **SG datasets.** OneMap themes `walking_routes`, `cycling_path_network`; NParks tree census for shade. See catalog B10, B18.
- **Discriminating power.** HIGH. Bukit Panjang / Sengkang / Tengah (covered-walkway-as-spine) vs older mature towns vary visibly. Easily clears ±0.3.
- **Cross-references.** Sweep A (AURIN walkability sub-index, 15-min-city literature); Sweep B (OneMap themes). Refines existing `conn`, not a new top-level component.

### 1d. Eldercare / ageing-in-place provision
- **Description.** Density of eldercare day-care, Active Ageing Centres (AAC), nursing homes, senior-care centres per 1000 residents aged 65+.
- **Provenance.** MEASURED. AIC Silver Pages + MOH eldercare registry + MSF data both exist.
- **Proposed weight bucket.** 0.03–0.05. Currently subsumed under `hlth` (0.07) which is GP-and-polyclinic-focused; eldercare is a distinct construct given SG's demographic trajectory.
- **SG datasets.** AIC Silver Pages (most complete); data.gov.sg eldercare-services (partial); MOH facility registry. See catalog B (MSF eldercare entry).
- **Discriminating power.** HIGH. Today's mature estates (Marine Parade, Queenstown, Bedok) are over-provisioned; new towns (Punggol, Sengkang, Tengah) under-provisioned. Demographic trajectory makes this increasingly important.
- **Cross-references.** Sweep A (WHO Age-Friendly Cities, OECD Better Life "health"); Sweep B (AIC/MOH/MSF). Borders existing `hlth`.

### 1e. Construction-disruption horizon (active near-term)
- **Description.** Sum of active BCA-permitted construction sites within 500m, weighted by remaining duration. Distinct in sign from `mom`: completions are positive momentum (`mom`); active disruption is negative living-now.
- **Provenance.** MEASURED. BCA permit data + HDB launch pipeline.
- **Proposed weight bucket.** Route through the D multiplier (losses-only) rather than a new component — this is what D was designed for. Or formalise as a temporary penalty that decays as projects complete. See Guardrail G2.
- **SG datasets.** BCA permits; HDB launch pipeline; URA Master Plan diffs. See catalog B21.
- **Discriminating power.** HIGH for affected estates (Tengah, Bidadari, parts of Pasir Ris). Already partially captured for Tengah via the existing P9.2 Estate Fill Ratio.
- **Cross-references.** Sweep B (BCA, HDB); Sweep C tier-2 ("next door BTO site for 5 years"). **Note routing:** this is a D-multiplier candidate, not a new Provision component — see G2.

## 2. JUDGED → MEASURED upgrades

### 2a. `mom` (momentum) — currently JUDGED → MEASURED for HDB estates
- **Upgrade path.** Stop hand-scoring HDB-side momentum from `pipeline_data.json` reading. Ingest HDB upgrading-programme block lists (HIP / NRP / LUP / EUP / HIP II) and the SERS / VERS announcement archive directly.
- **SG datasets.** data.gov.sg HDB upgrading datasets + HDB Infoweb PDF/HTML scrape. See catalog B6.
- **Limitation.** Private-side momentum (en-bloc, new launch pipeline) remains JUDGED; URA Master Plan diff parsing could partially close this but is a separate workstream.
- **Cross-references.** Sweep B; Sweep C tier-2 ("HIP coming or not", "kena SERS bonus").

### 2b. `dens` — PARTLY_MEASURED → MEASURED
- **Upgrade path.** Join HDB Property Information (block-level: year of completion, max storey, total dwelling units) with OneMap `hdb_existing_building` polygons → dwelling-units per hectare at block resolution. Augment with URA Master Plan GPR and SLA private-building polygons for private estates.
- **SG datasets.** `d_17f5382f26140b1fdae0ba2ef6239d2f` + OneMap `hdb_existing_building` [verify] + URA Master Plan land use. See catalog B4, B7, B9.
- **Note.** The "feel" component of `dens` remains JUDGED — being honest, the math gives us residents/hectare, not "feels dense", and the framework should keep that distinction.
- **Cross-references.** Sweep B.

### 2c. `hawker` — JUDGED → MEASURED (partially)
- **Upgrade path.** Switch from "fame/reputation" judgement to NEA Hawker Centre v2 GeoJSON: stall count, original completion date, operating-day pattern. Adds *redundancy* (single hawker centre closed Mondays = effective zero on those days) and density (stalls per centre per resident).
- **SG datasets.** `d_ccca3a7c2bbf5089e6789aab2120e198` [verify]. See catalog B3.
- **Limitation.** Hygiene grading is scrape-only and licence-restricted; "fame" is genuinely JUDGED.
- **Cross-references.** Sweep B; Sweep C tier-3 (wet-market sub-component distinct from hawker).

### 2d. `env` — PARTLY_MEASURED → MEASURED (incremental)
- **Upgrade path.** Split current single `env` score into:
  - Heat / shade (NParks tree census + OneMap NDVI proxy)
  - Flood resilience (already covered by `flood`)
  - Noise (already split — expressway in `noise`; aircraft proposed in §1a above)
  - Air quality (proposed §1b above)
- **Net effect.** Current `env` (0.05, PARTLY_MEASURED) becomes a residual "thermal comfort + microclimate" component (~0.02, MEASURED via tree census + temperature stations), with air and aircraft-noise as siblings.
- **SG datasets.** NParks tree data; NEA real-time temperature; see B18.

## 3. Nice-to-have (lower priority)

- **Heritage / character density** — URA Conservation Areas + NHB historic sites + monuments. Discriminates only at the tails (Tiong Bahru, Kampong Glam, Geylang, Joo Chiat); mid-distribution flat. Sweep A (Mercer socio-cultural, CLC distinctiveness); Sweep B B5, B15.
- **Carpark / EV charging provision** — HDB carpark info + LTA EV rollout data. Rising buyer concern (Sweep C tier-2), but cleanly belongs in the conditional S11 car-mobility branch (Doc 1 §1.2), not a top-level component.
- **15-minute-city composite** — collapses access-to-six-functions into one score. Already done piecewise (`conn`, `amen`, `green`, `sch`, `hlth`); a composite would duplicate, not add. Skip.
- **Wet-market presence** (distinct from hawker) — NEA wet market list. Adds a sub-metric to `amen`, not a new component.
- **Dengue cluster pressure** — NEA cluster GeoJSON. Real signal but the cluster archive isn't historical (only current); single-snapshot scoring is unfair.
- **Streetscape imageability (Place Pulse / Ewing-Handy)** — high discrimination but risks correlating with affluence (Axiom 2 watch). Defer until a class-laundering-audited open CV model exists.
- **Religious-infrastructure proximity** — MUIS / ROS / NEA data. Frame neutrally as "places-of-worship density"; Sweep C tier-3. Saturates in mature estates.
- **Pet-friendliness** — NParks dog-runs feed it cleanly. Niche; defer.
